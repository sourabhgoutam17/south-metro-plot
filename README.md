### CI/CD with GitHub Actions

This repository uses **GitHub Actions** for automatic deployment to GitHub Pages.

**Workflow file:** `.github/workflows/deploy.yml`

#### How it works
1. Every push to the `main` branch triggers the workflow
2. The site is packaged and deployed to GitHub Pages
3. You can also trigger it manually from the **Actions** tab

#### First-time setup (required)
1. Go to **Settings → Pages**
2. Under **Source**, select **GitHub Actions**
3. Save

After the first successful run, the live URL will appear in the Actions summary and on the Pages settings page.
